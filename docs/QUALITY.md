# 质量与 Golden Task Board / Quality and Golden Task Board

## 中文

公开 Golden Task Board 使用完全合成、可再分发的输入。它检查本仓库的技能契约、确定性脚本、路由与交接是否工作，不评判任何模型的科学创见或文笔，也不代表真实投稿结果。

每个任务都要求可检查的产物和边界：evidence 不得把元数据当作蕴含；writing 必须保留缺口；polishing 必须记录实质修改；figure 必须有可编辑导出与 QA；reviewer/response 不得虚构审稿人、实验或修订；workflow 只检查 metadata 链路。

CI 运行合成单元/验收测试、严格 evidence 验证、figure 回归、跨宿主安装、文档链接和公开路径扫描。真实稿件、审稿意见、原始数据和全文 PDF 不应进入公开仓库或测试夹具。

## English

The public Golden Task Board uses only synthetic, redistributable inputs. It checks repository contracts, deterministic helpers, routes, and handoffs; it does not score scientific insight, prose quality, or real submission outcomes.

Every task has an inspectable output and boundary: metadata is not entailment; missing evidence remains visible; material edits require a ledger; figures need editable exports and QA; reviewer/response work cannot invent reviews, experiments, or revisions; workflow checks metadata links only.

CI runs synthetic unit and acceptance tests, strict evidence validation, figure regression, cross-host installation, documentation links, and public-path scans. Real manuscripts, reviews, raw data, and full-text PDFs never belong in public fixtures.
